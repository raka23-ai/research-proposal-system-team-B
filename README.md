# Research Proposal and Faculty Supervision Management System

## Project Description

Research Proposal and Faculty Supervision Management System is a simple Java Swing project designed to manage the research proposal submission and faculty supervision process.

## Project Files

- LoginPage.java - Contains the Java Swing login page.
- illustration.png - Contains the illustration used in the login page.
- README.md - Project information.
- PROJECT_FEATURES.md - List of implemented features.
- CHANGELOG.md - History of project changes.
